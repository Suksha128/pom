# 🍬 Kaveri Heritage Foods — Artisanal Sweets & Operations Dashboard

An artisanal South Indian sweets and savories web application built with HTML5, CSS3, and vanilla JavaScript. Features a customer storefront with real-time shopping cart and an interactive operations & process flow dashboard.

[![Live Site](https://img.shields.io/badge/Live-Website-success?style=for-the-badge&logo=github)](https://suksha128.github.io/pom/)
[![Repository](https://img.shields.io/badge/GitHub-Repository-blue?style=for-the-badge&logo=github)](https://github.com/Suksha128/pom)

---

## 🌟 Key Features

### 1. Customer Storefront
- **Authentic Food Imagery**: High-resolution photography for all 9 artisanal sweets & savories.
- **Figma Manufacturer Profile**: Company emblem, Thanjavur heritage details, FSSAI registration (67676767676767), 4.8★ rating, and featured product thumbnails.
- **Dynamic Category Filtering**:
  - *All Items (9)*
  - *Featured Heritage (3)*
  - *Handmade Sweets (4)*
  - *Savories & Pickles (2)*
- **Interactive Cart Drawer**:
  - Add to cart with live quantity adjustment (`+` / `−`) and remove options.
  - Subtotal computation with persistent `localStorage` support.
  - Checkout modal with generated order ID and summary.

### 2. Operations & Process Flow Dashboard
- **Live KPI Counters**: Orders today, units in stock, low-stock alerts, active batches, and QA pass rates.
- **Three-Swimlane Process Flow**:
  1. **Customer Flow**: Discovery → Sweet Selection → Cart Drawer → Order Review → Order Confirmation.
  2. **Inventory Flow**: Raw Material Tracking → Low-Stock Threshold Alerts → Batch Tracking → Auto Stock Deductions.
  3. **Manufacturer Flow**: Order Reception → Recipe Batching → Hand-Crafting & QA Sensory Checks → Eco Packaging → Dispatch Updates.
- **Interactive Visual Elements**: Live progress indicators, stock level bars, and status legends.

## 🚀 Running Locally

No installation or build step required. Simply open `index.html` in any web browser:

```bash
git clone https://github.com/Suksha128/pom.git
cd pom
open index.html
```
